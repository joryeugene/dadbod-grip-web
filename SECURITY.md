# Security policy

## Supported version

The deployed website and the current `main` branch are supported.

## Report a vulnerability

Please use [GitHub's private vulnerability reporting](https://github.com/joryeugene/dadbod-grip-web/security/advisories/new) so the report stays private while it is investigated. Do not open a public issue for a suspected vulnerability.

Include the affected page or commit, reproduction steps, expected impact, and any mitigation you have already tested. Please omit real credentials and sensitive production data.

This repository contains the documentation website. Report vulnerabilities in Dadbod Grip itself through the [plugin repository's private reporting form](https://github.com/joryeugene/dadbod-grip.nvim/security/advisories/new).
